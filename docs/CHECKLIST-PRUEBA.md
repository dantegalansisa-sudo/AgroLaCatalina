# Checklist de prueba — un día con La Catalina POS

Marca cada punto cuando lo pruebes. Anota cualquier cosa rara para ajustarla.

## Al empezar el día (como administradora)
- [ ] Entrar con el usuario **admin** desde la computadora.
- [ ] Instalar la app: ícono de instalar en la barra de Chrome/Edge (o Configuración → Instalar).
- [ ] En el teléfono: abrir el enlace en Chrome (Android) → “Instalar aplicación”, o Safari (iPhone) → Compartir → “Agregar a pantalla de inicio”.
- [ ] Configuración: revisar nombre, dirección, teléfono y mensaje del recibo. Subir el logo si lo tienes.
- [ ] Productos → filtro **Sin precio**: completar precios de algunos productos que vendas hoy.
- [ ] Agregar el **costo** a 3–5 productos para ver la ganancia en Dashboard y Reportes.
- [ ] Caja → abrir caja con el efectivo inicial.

## Vendiendo
- [ ] Venta en efectivo: tocar productos, cobrar, poner lo recibido y ver el **cambio**.
- [ ] Usar la búsqueda (F2) y escribir parte del nombre; Enter agrega si hay un solo resultado.
- [ ] Probar los chips de categoría.
- [ ] Descuento en una línea (botón “Desc.”) y descuento total (RD$ o %).
- [ ] Venta por **transferencia** con referencia.
- [ ] Venta **fiado**: elegir o crear un cliente en el momento.
- [ ] Venta **mixta**: parte efectivo + parte transferencia o fiado.
- [ ] Recibo: **Imprimir** (impresora térmica de 80 mm), **PDF** y **WhatsApp**.
- [ ] Desde el teléfono: hacer una venta con el carrito en el panel inferior.
- [ ] Escanear un código con la cámara del teléfono (primero asigna el código de barras al producto en Productos).
- [ ] Si tienes lector USB: escanear con el lector en la pantalla de Vender.
- [ ] Intentar vender más de lo que hay en stock (debe avisar).

## Inventario y clientes
- [ ] Inventario → **Entrada de mercancía** de un producto (con costo y proveedor).
- [ ] Inventario → **Ajuste** con motivo (ej. conteo físico).
- [ ] Ver el historial de movimientos de ese producto.
- [ ] Clientes → registrar un **abono** a un cliente con fiado y ver bajar el balance.
- [ ] Enviar recordatorio de balance por WhatsApp.

## Cajero (en otra computadora o teléfono)
- [ ] Entrar con el usuario **cajero**.
- [ ] Confirmar que **no** ve costos, ganancias, Inventario, Reportes, Usuarios ni Configuración.
- [ ] Abrir su caja, vender y cerrar su caja.

## Administración
- [ ] Ventas → abrir una venta, **reimprimir** y **anular** con motivo (el stock vuelve).
- [ ] Reportes: cambiar entre Hoy / 7 días / Este mes / Rango, y entre Día / Semana / Mes.
- [ ] Descargar el reporte en **PDF** y en **Excel/CSV**.
- [ ] Usuarios: crear un usuario de prueba, desactivarlo y volver a activarlo.
- [ ] Productos → **Exportar** y abrir el CSV en Excel.

## Al cerrar el día
- [ ] Caja → **Cerrar caja** contando billetes; revisar sobrante/faltante.
- [ ] Revisar el Dashboard: ventas de hoy, más vendidos y alertas.

## Antes de usarlo de verdad
- [ ] Crear los usuarios reales (dueña y cajeros).
- [ ] Configuración → **Limpiar datos demo** (y opcionalmente poner stock en 0 y eliminar usuarios demo).
- [ ] Cargar el inventario real (Entradas o Importar CSV).
